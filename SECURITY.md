# Security Policy

bdate is a small, dependency-free library (Python and JavaScript), a
command-line tool, and a static site. There are no user accounts, no server
code and no stored user data: the clock app computes everything in the
browser, and the place you pick (or your location, if you share it) stays in
that browser's local storage.

If you believe you've found a security issue anyway, for example a way to
make the clock page run someone else's script, please report it privately
rather than in a public issue: use **Report a vulnerability** on the
repository's [Security tab](https://github.com/thekyria/bdate/security), or
contact the maintainer directly.
