# bdate

`date(1)`, but the way a Byzantine would have reckoned it.

```
$ bdate
Kyriakē, 21 Septembrios 7535 AM (Julian 2026-09-21), indiction 5, 6th hour of the day
```

📖 **Documentation & theory:** <https://thekyria.github.io/bdate/>
(source in [`docs/`](docs/))

🕰 **Live clock:** <https://bdate.app/>. Embed it with
`<iframe src="https://bdate.app/?compact=1" width="320" height="320" style="border:0"></iframe>`.
Options: `place=athens` (or another preset), `lat=…&lon=…`, `theme=light|dark`.
To preview locally: `cp js/src/bdate.js docs/clock/ && python3 -m http.server -d docs`,
then open <http://localhost:8000/clock/>.
The clock is installable as an app ("Install" or "Add to Home Screen" in the
browser) and works offline. To host it on Vercel, import this repo: `vercel.json`
copies `bdate.js` in and serves `docs/clock/` as the site root.

🔌 **Web API:** <https://bdate.app/api/v1/date> returns `bdate --json`'s output;
it takes `date`, `tz`, `lat`, `lon` and `hours=0` (see
[Usage](https://thekyria.github.io/bdate/usage.html#web-api)).

## Layout

| Path | What |
|---|---|
| [`python/`](python/) | The reference implementation and the `bdate` command-line tool |
| [`js/`](js/) | A JavaScript port of the same reckoning, for web pages and Node |
| [`fixtures/`](fixtures/) | Cases generated by the Python package; both test suites check them |
| [`docs/`](docs/) | The GitHub Pages site |
| [`api/`](api/) | The bdate.app web API, a Vercel function on top of the JS port |
| [`tests/clock/`](tests/clock/) | Checks for the clock app: its files and a browser smoke test |
| [`tests/api/`](tests/api/) | Tests for the web API |

Python is the source of truth. After changing the logic there, regenerate the
fixtures (`cd python && uv run python scripts/gen_fixtures.py`). The Python
tests fail while the fixtures are stale, and the JS tests fail until the port
matches them.

## Quick start

```
uvx --from ./python bdate          # command line
cd js && npm test                  # JS port tests (Node ≥ 18, no dependencies)
node --test tests/api/date.test.mjs   # web API
cd tests/clock && npm ci && npx playwright install chromium && npm test   # clock app
```

```js
import { byzantine, formatDefault } from "./js/src/bdate.js";
formatDefault(byzantine(new Date(), { lat: 37.98, lon: 23.73 }));
```
