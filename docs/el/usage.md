# Χρήση

[← Επισκόπηση](index.md)

## Εγκατάσταση

Το `bdate` χρειάζεται μόνο την τυπική βιβλιοθήκη και Python 3.9 ή νεότερη.

Από ένα αντίγραφο του αποθετηρίου (το πακέτο Python βρίσκεται στο `python/`):

```
uv tool install ./python    # εγκατάσταση της εντολής `bdate` για όλο το σύστημα
uvx --from ./python bdate   # εκτέλεση χωρίς εγκατάσταση
pip install ./python        # δουλεύει και με σκέτο pip
```

Μια έκδοση σε JavaScript χωρίς εξαρτήσεις, με την ίδια έξοδο, βρίσκεται στο `js/`,
για χρήση σε ιστοσελίδες.

## Γραμμή εντολών

| Επιλογή | Αποτέλεσμα |
|---|---|
| *(καμία)* | Μετατρέπει την τρέχουσα στιγμή, σε τοπική ώρα |
| `-u`, `--utc` | Χρησιμοποιεί UTC αντί για την τοπική ώρα |
| `-d ISO`, `--date ISO` | Μετατρέπει μια ημερομηνία-ώρα ISO-8601 αντί για την τρέχουσα στιγμή (διαβάζεται ως **γρηγοριανή**) |
| `--lat`, `--lon` | Τόπος για την ανατολή/δύση (προεπιλογή: Κωνσταντινούπολη) |
| `--no-hours` | Παραλείπει τον υπολογισμό της καιρικής ώρας |
| `--json` | Τυπώνει JSON για επεξεργασία από προγράμματα |
| `-V`, `--version` | Τυπώνει την έκδοση |

Αν δώσετε στο `-d` ημερομηνία-ώρα χωρίς διαφορά από το UTC, το `bdate`
χρησιμοποιεί την τοπική ζώνη ώρας, ή το UTC αν δώσετε και το `-u`.

## Πώς διαβάζεται η έξοδος

```
Tritē, 29 Maios 6961 AM (Julian 1453-05-29), indiction 1, 2nd hour of the day
└─┬─┘  └────┬────┘ └─┬─┘  └────────┬──────┘  └────┬────┘  └────────┬────────┘
όνομα  ημέρα +     έτος   ιουλιανή           ινδικτιώνα   καιρική ώρα
ημέρας μήνας       κόσμου ημερομηνία
```

Τη νύχτα το τμήμα της ώρας γράφει, για παράδειγμα, `5th hour of the night (2nd watch)`
(5η ώρα της νύχτας, 2η φυλακή).

## Πεδία του JSON

| Πεδίο | Σημασία |
|---|---|
| `gregorian` | Η στιγμή εισόδου, σε ISO-8601 |
| `julian_year`, `julian_month`, `julian_day` | Η ιουλιανή ημερομηνία |
| `month_name`, `weekday` | Τα βυζαντινά ονόματα σε λατινική μεταγραφή |
| `anno_mundi` | Το έτος από κτίσεως κόσμου |
| `indiction` | 1–15 |
| `seasonal` | `null`, ή `{period, hour, watch, start, end}` |

## Web API

Το `https://bdate.app/api/v1/date` επιστρέφει το ίδιο JSON μέσω HTTP, μαζί με το
`text` (την έξοδο σε μία γραμμή) και τα `lat` και `lon` που χρησιμοποίησε:

```
$ curl 'https://bdate.app/api/v1/date?date=1453-05-29T05:30&tz=Europe/Istanbul'
{"gregorian":"1453-05-29T05:30:00+01:55", …, "text":"Kyriakē, 20 Maios 6961 AM (Julian 1453-05-20), indiction 1, 1st hour of the day", …}
```

| Παράμετρος | Αποτέλεσμα |
|---|---|
| *(καμία)* | Μετατρέπει την τρέχουσα στιγμή, σε UTC, για την Κωνσταντινούπολη |
| `date` | Μια ημερομηνία-ώρα ISO-8601 αντί για την τρέχουσα στιγμή (διαβάζεται ως **γρηγοριανή**) |
| `tz` | Μια ζώνη ώρας IANA, π.χ. `Europe/Athens`: η ημερομηνία και οι ώρες δίνονται με τη διαφορά της |
| `lat`, `lon` | Τόπος για την ανατολή/δύση |
| `hours=0` | Παραλείπει τον υπολογισμό της καιρικής ώρας |

Ένα `date` με διαφορά από το UTC κρατά αυτή τη διαφορά, εκτός αν δώσετε και `tz`.
Ένα χωρίς διαφορά διαβάζεται στη ζώνη `tz`, ή σε UTC. Μια λανθασμένη είσοδος
παίρνει απάντηση `400` με μήνυμα στο `error`. Πριν από το 1970 περίπου, οι ζώνες
ώρας πέφτουν στον τοπικό μέσο χρόνο (της Κωνσταντινούπολης είναι `+01:55`), οπότε
για παλιές ημερομηνίες ίσως προτιμήσετε μια ρητή διαφορά, όπως `+02:00`.

### Πρόγραμμα

Το `https://bdate.app/api/v1/schedule` δίνει τον ίδιο υπολογισμό για ένα χρονικό
διάστημα, για widgets και άλλες εφαρμογές που δεν μπορούν να τον κάνουν μόνες
τους. Ζητήστε το μία ή δύο φορές τη μέρα και δείξτε το διάστημα που περιέχει την
τρέχουσα στιγμή:

```
$ curl 'https://bdate.app/api/v1/schedule?date=2026-10-18T10:00&tz=Europe/Athens&lat=37.98&lon=23.73'
{"from":"2026-10-18T10:00:00+03:00","to":"2026-10-19T10:23:26+03:00","lat":37.98,"lon":23.73,
 "segments":[{"from":"2026-10-18T10:00:00+03:00","to":"2026-10-18T10:23:02+03:00","julian_year":2026, …, "text":"…, 3rd hour of the day"}, …]}
```

Δέχεται τις ίδιες παραμέτρους με το `/api/v1/date`, και επιπλέον το `span`: τις
ώρες που καλύπτει από το `date`, από 1 έως 168 (προεπιλογή 24). Κάθε διάστημα
έχει `from`, `to` και τα πεδία που επιστρέφει το `/api/v1/date` σε οποιαδήποτε
στιγμή ανάμεσά τους (χωρίς τα `gregorian`, `lat` και `lon`). Ένα νέο διάστημα
αρχίζει σε κάθε όριο καιρικής ώρας, τα μεσάνυχτα και όταν η ζώνη `tz` αλλάζει
διαφορά. Το πρώτο διάστημα αρχίζει στο `date` και το τελευταίο τελειώνει στο
`date` + `span` ή λίγο μετά.
