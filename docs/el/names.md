# Ημέρες και μήνες

[← Επισκόπηση](index.md)

Το `bdate` τυπώνει τα ονόματα των ημερών και των μηνών σε λατινική μεταγραφή
της βυζαντινής ελληνικής. Το [ρολόι](https://bdate.app/?lang=el) στα ελληνικά τα
γράφει με ελληνικούς χαρακτήρες.

## Ημέρες της εβδομάδας

Η χριστιανική ελληνική εβδομάδα μετρά τις ημέρες από την Ημέρα του Κυρίου. Μόνο η
Παρασκευή (η προετοιμασία) και το Σάββατο έχουν δικά τους ονόματα:

| bdate | Ελληνικά | Σημασία | Αγγλικά |
|---|---|---|---|
| Kyriakē | Κυριακή | (η ημέρα) του Κυρίου | Sunday |
| Deutera | Δευτέρα | δεύτερη | Monday |
| Tritē | Τρίτη | τρίτη | Tuesday |
| Tetartē | Τετάρτη | τέταρτη | Wednesday |
| Pemptē | Πέμπτη | πέμπτη | Thursday |
| Paraskeuē | Παρασκευή | προετοιμασία (για το Σάββατο) | Friday |
| Sabbaton | Σάββατον | Σάββατο | Saturday |

Αυτά είναι τα εκκλησιαστικά ονόματα, που τα χρησιμοποιούν ακόμη τα νέα ελληνικά.
Τα παλαιότερα ειδωλολατρικά πλανητικά ονόματα («ημέρα του Ηλίου», «ημέρα της
Σελήνης», …) εγκαταλείφθηκαν στη χριστιανική χρήση, και το `bdate` δεν τα
υποστηρίζει.

## Μήνες

Οι Βυζαντινοί πήραν τα λατινικά ονόματα των μηνών σε ελληνική μορφή:

| bdate | Ελληνικά | Μήνας |
|---|---|---|
| Ianouarios | Ἰανουάριος | Ιανουάριος |
| Phebrouarios | Φεβρουάριος | Φεβρουάριος |
| Martios | Μάρτιος | Μάρτιος |
| Aprilios | Ἀπρίλιος | Απρίλιος |
| Maios | Μάϊος | Μάιος |
| Iounios | Ἰούνιος | Ιούνιος |
| Ioulios | Ἰούλιος | Ιούλιος |
| Augoustos | Αὔγουστος | Αύγουστος |
| Septembrios | Σεπτέμβριος | Σεπτέμβριος |
| Oktōbrios | Ὀκτώβριος | Οκτώβριος |
| Noembrios | Νοέμβριος | Νοέμβριος |
| Dekembrios | Δεκέμβριος | Δεκέμβριος |

Το επίσημο έτος άρχιζε τον Σεπτέμβριο, γι' αυτό οι βυζαντινοί κατάλογοι (για
παράδειγμα το Μηνολόγιο) συνήθως ξεκινούν από τον Σεπτέμβριο. Εσωτερικά το
`bdate` ακολουθεί την αρίθμηση μηνών του Ιουλιανού ημερολογίου (1 = Ιανουάριος).
Τον Σεπτέμβριο αλλάζει μόνο ο αριθμός του έτους.

## Μεταγραφή

Η γραφή είναι μια απλή μεταγραφή με μακρά για το η (ē) και το ω (ō). Δεν έχει
άλλα διακριτικά, ώστε να εμφανίζεται σε οποιοδήποτε τερματικό.
